# Glossary

Approved terms per language, to keep translations consistent. Add a row whenever a new
music or app term appears in the UI or in lessons.

Note names themselves (C / Do / H) are **not** translated: they come from the note-naming
system setting (`src/i18n/naming.ts`).

| Concept                          | English            | Español                   |
| -------------------------------- | ------------------ | ------------------------- |
| Key (on the piano)               | key                | tecla                     |
| Key pressed / released           | down / up          | pulsada / soltada         |
| Octave                           | octave             | octava                    |
| Note names (setting)             | note names         | nombres de las notas      |
| English letter names             | English letters    | letras inglesas           |
| German letter names              | German letters     | letras alemanas           |
| Solfège                          | solfège            | solfeo                    |
| Sustain pedal                    | sustain pedal      | pedal de resonancia       |
| Velocity (how hard a key is hit) | velocity           | velocidad                 |
| Digital piano                    | digital piano      | piano digital             |
| MIDI keyboard                    | MIDI keyboard      | teclado MIDI              |
| Computer keyboard                | computer keyboard  | teclado de la computadora |
| Free play                        | free play          | práctica libre            |
| Learning path                    | learning path      | camino de aprendizaje     |
| Lesson                           | lesson             | lección                   |
| Progress                         | progress           | progreso                  |
| Practice streak                  | practice streak    | racha de práctica         |
| On-screen keyboard               | on-screen keyboard | teclado en pantalla       |
| Falling notes                    | falling notes      | notas que caen            |
| Song                             | song               | canción                   |
| Play (start playback)            | play               | tocar                     |
| Start over                       | start over         | volver a empezar          |
| Wait mode                        | wait for me        | espérame                  |
| Tempo mode                       | play along         | tocar a tempo             |
| Metronome                        | metronome          | metrónomo                 |
| Count-in                         | count-in           | entrada (del metrónomo)   |
| Right / left hand                | right / left hand  | mano derecha / izquierda  |
| Accuracy                         | accuracy           | precisión                 |
| Wrong key                        | wrong key          | tecla incorrecta          |
| Missed note                      | missed             | perdida                   |
| Notes in a row (streak)          | in a row           | seguidas                  |
| Microphone                       | microphone         | micrófono                 |
| Background noise                 | background noise   | ruido de fondo            |
| Threshold (mic gate)             | threshold          | umbral                    |
| Delay (latency)                  | delay              | retraso                   |
| Calibration                      | calibration        | calibración               |
| Listen to (input choice)         | listen to          | escuchar                  |

Spanish uses neutral Latin American vocabulary ("computadora", not "ordenador") and the
informal "tú".
